# r2SCAN Transfer Results

This directory contains the locked r2SCAN transfer/data-efficiency tables, bootstrap tests, config audit, leakage audit, and cost accounting.

Classical delta-learning reaches 16.42 meV/atom in the full-label setting, while canonical FormDelta reaches 17.81 meV/atom. The README intentionally reports both values.

Latent-feature delta-learning was not evaluated because a split-aligned r2SCAN latent representation cache was unavailable.
